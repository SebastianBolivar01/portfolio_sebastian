# 🚀 Sebastian Bolivar - Portfolio

Welcome to my professional portfolio! This is a modern, high-performance web application built with **Next.js 15**, **React 19**, and **TypeScript**.

## ✨ Features

- **🌍 Multilingual Support**: English, Spanish, Italian, and Portuguese.
- **🌓 Theme Switching**: Dark and Light modes with persistent state.
- **📱 Responsive Design**: Fully optimized for mobile, tablet, and desktop.
- **🎨 Glassmorphism UI**: Beautiful "Aurora Tech" aesthetics with subtle animations.
- **⚡ Performance**: Built with Next.js App Router for optimal loading speeds.
- **🔍 SEO Optimized**: Custom metadata, robots.txt, and sitemap.xml.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Vanilla CSS (CSS Modules approach)
- **Icons**: [DevIcon](https://devicon.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 📂 Project Structure

```bash
├── app/
│   ├── components/    # Reusable UI components
│   ├── hooks/         # Custom React hooks (useTheme, useLanguage)
│   ├── types/         # TypeScript definitions
│   ├── globals.css    # Global styles & Aurora variables
│   └── page.tsx       # Main entry point
├── public/            # Static assets
└── i18n.ts            # Internationalization logic
```

## 🏗️ Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SebastianBolivar01/portfolio_sebastian.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```
